# ⚡ ElectroFix — Landing Page

Адаптивный одностраничный сайт для сервиса по ремонту и продаже электрокаров. Выполнен в стиле современного брутализма (loft/tech) с акцентом на сетку, типографику и кислотный лайм.

## 🚀 Демо

**[Посмотреть сайт вживую](https://Ruslan-study.github.io/electrofix-landing-page/)** *(если GitHub Pages ещё не включён — ссылка появится после его активации)*

## 🛠 Технологии

- **HTML5** — семантическая верстка
- **CSS3** — Grid, Flexbox, CSS-переменные, медиазапросы
- **Vanilla JavaScript** — мобильное меню, валидация формы, `IntersectionObserver` для анимаций появления блоков при скролле
- **Google Fonts** — Space Grotesk, Inter, JetBrains Mono

## 📱 Особенности

- Полностью адаптивный дизайн (от мобильных до широких экранов)
- Плавные анимации при скролле (`IntersectionObserver`)
- Эффекты наведения (hover) на карточки товаров и услуги
- Валидация формы обратной связи
- Стилизация под лофт-тех: сетка на фоне, угловатые формы, моноширинные шрифты
